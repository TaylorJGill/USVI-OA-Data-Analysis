# USVI Ocean Acidification Data Analysis

A data pipeline and report built for UVI marine scientists studying ocean 
acidification in the U.S. Virgin Islands. Multi-instrument data from a 
3–5 year field experiment was ingested, cleaned, and organized into an 
interactive HTML report to support scientific review and publication.

## What I Did
- Received raw, multi-instrument sensor data from field scientists at UVI
- Cleaned and organized data from SeaFETs, EcoPARs, SAMI CO2 sensors, and SBE37s
- Analyzed data from two reef sites: Brewers Bay (nearshore, 6m) and Hind Bank 
  (mesophotic, 39m)
- Investigated whether upwelling at deeper sites led to periodic acidification
- Generated an interactive HTML report for technical and non-technical stakeholders

## Tools Used
R, R Markdown
